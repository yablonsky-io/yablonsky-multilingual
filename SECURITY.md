# Security policy

Yablonsky Multilingual takes security reports seriously. If you discover a possible vulnerability, please do not include exploit instructions, credentials, or personal information in a public GitHub issue.

Use GitHub private vulnerability reporting if it is enabled for this repository. Otherwise contact the Yablonsky.io project privately through its official website: https://yablonsky.io/.

Please include the affected version, expected behavior, observed behavior and a minimal, non-sensitive reproduction case.
